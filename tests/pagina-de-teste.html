Recorte — teste de formatos

Selecione o bloco de cada caso, botão direito, Exportar seleção. Os arquivos saem na pasta Downloads com o nome desta página.

Antes de começar: chrome://extensions → ↻ no cartão do Recorte. Extensão sem compactação não recarrega sozinha, e isso já custou uma rodada hoje.
1JSON de API, indentado Automático → .json indentado com 2 espaços
{
  "id": 7,
  "nome": "Ana Ribeiro",
  "ativo": true,
  "tags": ["a", "b"],
  "endereco": { "cidade": "Uberlândia", "uf": "MG" }
}
2JSON em uma linha só Automático → .json, agora quebrado em linhas
{"id":7,"nome":"Ana","lista":[1,2,3],"vazio":{},"nulo":null}
3O caso que justifica a extensão inteira Automático → .json. Abra o arquivo e confira: o inteiro gigante tem que sair idêntico, a chave repetida tem que continuar duas vezes, e 1.0, 1e3 e -0 não podem virar outra coisa. Qualquer formatador que faça parse e stringify estraga os cinco.
{
  "id_grande": 9007199254740993,
  "a": 1,
  "a": 2,
  "decimal": 1.0,
  "cientifico": 1e3,
  "zero_negativo": -0,
  "unicode": "é o mesmo que é?"
}
4JSON cortado no meio Automático → .txt. Agora force .json: sai .txt, o ícone acende TXT laranja, e o botão Erros do cartão diz o motivo.
{
  "id": 7,
  "nome": "Ana Ribeiro",
  "end
5XML bem formado Automático → .xml indentado
<?xml version="1.0" encoding="UTF-8"?>
<reserva id="4471"><hospede><nome>Ana</nome><documento tipo="cpf">000</documento></hospede><noites>3</noites></reserva>
6XML com conteúdo misto Automático → .xml. O elemento <p> tem que sair literal, byte a byte — ali o espaço antes de <b> é conteúdo, e indentar mudaria o que o documento diz.
<doc><titulo>Aviso</titulo><p>Olá <b>mundo</b>, tudo <i>bem</i>?</p></doc>
7XML com namespace, CDATA, comentário e entidade Automático → .xml. Confira que o prefixo x: não foi reescrito, o CDATA saiu inteiro e &amp; continua escrito assim, sem virar &.
<x:raiz xmlns:x="http://exemplo/ns"><!-- nota --><x:item>a &amp; b</x:item><x:bruto><![CDATA[ if (a < b && c > d) {} ]]></x:bruto></x:raiz>
8XML com atributo sem aspas Automático → .txt. Isto é HTML tolerante, não XML — a norma exige aspas. Era o único ponto em que o meu validador discordava do navegador; foi corrigido agora.
<a t=1><b/></a>
9XML mal formado Automático → .txt. Force .xml: sai .txt e acende TXT.
<a><b>um</a></b>
10Texto comum Automático → .txt, sem selo. Texto não é falha.

11Código indentado Automático → .txt com a indentação intacta. A linha em branco dupla também tem que sobreviver.
def processar(itens):
    total = 0
    for i in itens:
        if i > 0:
            total += i

    return total
12Campo de formulário Clique dentro, Ctrl+A, Automático → .json. Dentro de <textarea> o getSelection() volta vazio; a extensão lê por selectionStart. Caminho diferente do resto.
13Seleção dentro de um iframe Automático → .json. Testa se a injeção vai no frame do clique e não no topo. Se for no topo, a seleção lida é a errada.
Os dois últimos não têm bloco, são navegação:
14. Abra chrome://settings, selecione qualquer texto, botão direito. O menu do Recorte não deve nem aparecer.
15. Clique duas vezes seguidas, rápido, em qualquer caso acima. Dois arquivos, nenhum erro — só pode existir um documento offscreen.
Enquanto testa, vale deixar chrome://extensions aberto numa aba. Qualquer falha de verdade aparece no botão Erros do cartão, com o motivo — sem precisar de DevTools.
